Events Management

Upload event data

Upload an event admin PDF, Excel file, or CSV. The file creates or updates the event, participation, and Date Stats. The default fee is €5 per participant and is marked paid. For Excel/CSV, use one row per participant; separate interest names with commas.

Record a failed event

Record a planned event that did not happen. Add the people who clicked “Attend” and “Not attending”; no attendance or money will be counted. Use one participant email per line or separate emails with commas.
